## 2024-10-10 - Unlinked form labels and broken keyboard navigation in authentication forms
**Learning:** React authentication forms often contain custom-styled inputs wrapping HTML `<input>` elements. If `id` and `htmlFor` are missing, screen readers fail to associate the `<label>` context to the input correctly. Additionally, custom elements like "show/hide password" buttons are frequently given `tabIndex={-1}` by developers assuming it removes them from the flow, but it actually breaks keyboard accessibility by preventing users from tabbing to it.
**Action:** Always ensure custom `<label>` and `<input>` pairings use explicit `htmlFor` and `id` linking. Make sure all interactive elements (like the password toggle) are reachable via keyboard without `tabIndex={-1}`, and have appropriate `focus-visible` styling and ARIA attributes for non-mouse users.
